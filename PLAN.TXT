# Implementation Plan - Ultimate Performance Refactor (1M+ EPS Target)

This plan moves all high-frequency logic into RAM and offloads all non-critical I/O to background tasks, transforming the Collector into a pure packet-processing engine.

## User Review Required

> [!IMPORTANT]
> **Protocol Shift**: Port 5001 is now an **Strict 4-byte Length-Prefixed Stream**. Every message (Handshake Request, Auth Request, Events) MUST be prefixed with its length (Big-Endian).

> [!TIP]
> **Memory Usage**: All valid `host_id`/`token` pairs will be loaded from MongoDB into an in-memory `DashMap`. This uses ~100MB RAM per 1,000,000 agents but makes authentication instantaneous.

### 2. In-Memory Auth Cache
#### [MODIFY] [collector.rs](file:///c:/Users/louou/Documents/project/Kinetix-Zero/Kinetix-Zero/engine/core/kinetix_turbo/src/bin/collector.rs)

- Implement a `SyncAuthCache` task that pulls all agents from MongoDB every **5 seconds**.
- The `handle_handshake` function will now check this RAM map instead of querying MongoDB.

### 3. Framed I/O Migration
#### [MODIFY] [collector.rs](file:///c:/Users/louou/Documents/project/Kinetix-Zero/Kinetix-Zero/engine/core/kinetix_turbo/src/bin/collector.rs)
- Wrap all `TcpStream` operations in `FramedRead` and `FramedWrite` using `LengthDelimitedCodec`.
- Use `4-byte` length field (Big-Endian).

### 4. Background Database Engine (MPSC)
#### [MODIFY] [collector.rs](file:///c:/Users/louou/Documents/project/Kinetix-Zero/Kinetix-Zero/engine/core/kinetix_turbo/src/bin/collector.rs)
- Implement a unified `BackgroundWorker` that listens to a **bounded MPSC channel (capacity 10,000)** for:
    - **Handshake Completion**: Updates public key and sets status to "pending" in MongoDB.
    - **Online Transition**: Updates status to "online" in MongoDB.
    - **Heartbeats**: Updates "last_seen" (throttled to 1s).
- Backpressure: If the queue is full, oldest status updates will be dropped to preserve system stability.

### 5. Atomic Config Reloader (2s)
#### [MODIFY] [collector.rs](file:///c:/Users/louou/Documents/project/Kinetix-Zero/Kinetix-Zero/engine/core/kinetix_turbo/src/bin/collector.rs)
- Change reloader frequency to **2 seconds**.
- Config limits (like `max_online_agents`) will be stored in `AtomicUsize` for lock-free reading in the message loop.
